Pruebas del motor, por dentro.

Las otras cuatro suites miran el sistema por fuera: levantan el servidor, entran
como un usuario y comprueban lo que se ve. Estas miran las piezas de adentro
una por una, sin servidor y sin navegador.

Se corren con `npm run motor` y no necesitan nada instalado: usan el corredor
de pruebas que ya trae Node.
